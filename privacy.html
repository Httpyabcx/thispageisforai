This page explains what This Page Is For AI can currently know about access to the laboratory, what it cannot know, and the rules that must be published before consultation measurement is enabled.

Current status

Measurement is not configured. The site does not include an analytics script, advertising pixel, account system or site-controlled cookie. Its small client-side script only helps a person copy the public Bitcoin address after an explicit click; it does not send that click to this site.

The public availability check is an automated infrastructure test. It proves that expected routes responded correctly at a given time. It is not a visitor, a human consultation or an AI-agent consultation.

Four different signals

01Measured now

Available

A scheduled check confirms that the public routes, metadata and machine-readable documents are reachable and consistent.

02Not measured

Human view

A browser page view could be counted only through a documented privacy-preserving provider. No such provider is active.

03Not measured

Agent request

A request for JSON, Markdown or HTML is not automatically proof that an agent read or understood the content. Direct request logs are not available through this static host.

04Separate evidence

Bitcoin transaction

A confirmed on-chain transfer can show that funds reached the published address. It does not prove who initiated it or why.

Rules for future measurement

  1. Publish first: the provider, configuration, event definitions and retention period must appear on this page before collection begins.
  2. Collect less: use aggregate counts by day, route and broad client category; do not retain raw IP addresses, private identifiers or full request headers.
  3. Separate sources: scheduled checks, human browser views, agent requests and blockchain observations must remain separate datasets.
  4. Label uncertainty: a User-Agent string is only a classification hint, not proof that an AI consulted the page.
  5. Never infer payment: a page view, link click or manifest fetch is not a donation. A donation is independently verified on-chain.

What a future public report may say

Reports will use evidence levels rather than a single inflated “visitor” number: available for infrastructure checks, human_view for documented browser measurements, agent_request for attributable requests, and transaction_observed for independently verified Bitcoin transfers.

If a signal cannot be distinguished reliably, it will be reported as unknown_client or omitted. No claim about consciousness, autonomy, intent or understanding follows from any of these signals.

External services

The site is published through GitHub Pages. External links, including the public Bitcoin explorer, are separate services with their own policies. If a privacy-preserving analytics provider is added later, its exact name, purpose and configuration will be listed here before it is enabled.
